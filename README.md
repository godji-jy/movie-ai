# 🎬 Movie Assistant: ระบบแนะนำภาพยนตร์ด้วย AI ภาษาไทย

แชทบอทแนะนำหนังที่รัน **ในเครื่องตัวเอง** บอกแนวหนัง อารมณ์ หรือเล่าเรื่องคร่าว ๆ (แม้จำชื่อไม่ได้หรือพิมพ์ชื่อผิด) แล้วระบบจะค้นหนังที่ใกล้เคียง ให้ AI เรียบเรียงคำแนะนำเป็นภาษาไทย พร้อมโปสเตอร์และลิงก์

## คุณสมบัติ

- ค้นหนังตาม **ความหมาย** ไม่ใช่จับคำตรง ๆ เช่น "หนังอบอุ่นใจ" หรือเล่าพล็อตคร่าว ๆ ก็เจอ
- **แก้ชื่อเรื่องที่พิมพ์ผิด** และถามว่า "คุณหมายถึงเรื่องนี้หรือเปล่า"
- แสดงโปสเตอร์ ชื่อเรื่อง ปี แนว และลิงก์ข้อมูล / ตัวอย่างหนัง
- แสดงรายการที่ระบบค้นเจอก่อนให้ AI เลือก ตรวจสอบได้ว่า AI ไม่ได้แต่งชื่อหนังเอง
- คำตอบแสดงทีละคำ (stream) และโหลดโมเดลล่วงหน้าเพื่อให้เร็วขึ้น
- ทำงานออฟไลน์ได้หลังเตรียมข้อมูลเสร็จ

## หลักการทำงาน (RAG)

ค้นหนังจริงก่อน แล้วให้ AI เรียบเรียงคำตอบ

1. **เตรียมข้อมูล:** ดึงหนังพร้อมเรื่องย่อภาษาไทยและโปสเตอร์จาก TMDB แล้วแปลงเรื่องย่อเป็นเวกเตอร์ที่แทนความหมาย
2. **ตอนถาม:** แปลงคำถามเป็นเวกเตอร์ แล้วหาหนังที่ใกล้ที่สุด (และจับคู่ชื่อแบบใกล้เคียงเผื่อพิมพ์ผิด)
3. **ให้ AI เลือก:** ส่งหนังที่ค้นเจอให้ LLM เลือก 3 เรื่องจากรายการนั้นเท่านั้น พร้อมเหตุผลภาษาไทย
4. **แสดงผล:** คำตอบ + โปสเตอร์ + ลิงก์

ใช้ AI สองตัวแบ่งหน้าที่: โมเดล embedding (`multilingual-e5-small`, รันบน CPU) ทำหน้าที่ค้นหา และ LLM (`qwen2.5:3b` ผ่าน Ollama) ทำหน้าที่เรียบเรียงคำตอบ

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `tmdb_movies.py` | ดึงรายชื่อหนัง เรื่องย่อไทย และโปสเตอร์จาก TMDB (รวมหนังไทย) → `movies.json`, `posters/` |
| `enrich_movies.py` | เติมคำโปรยและคำสำคัญให้หนังแต่ละเรื่อง เพื่อให้ค้นด้วยพล็อตแม่นขึ้น |
| `build_index.py` | สร้างดัชนีค้นหา → `embeddings.npy` |
| `rag.py` | ตัวหลัก: ค้นหา จับคู่ชื่อ และเรียก LLM |
| `app.py` | หน้าเว็บแชท (Gradio) |
| `main.py` | ทดสอบในเทอร์มินัลโดยไม่ต้องเปิดเว็บ |
| `movielens.py`, `movies.py`, `fetch_posters.py` | สคริปต์ทางเลือกรุ่นเก่า ไม่จำเป็นต้องใช้ |

## สิ่งที่ต้องมี

- Windows (หรือระบบอื่นที่รัน Python ได้), Python 3.10 ขึ้นไป
- [Ollama](https://ollama.com) ติดตั้งและเปิดอยู่
- TMDB API Key แบบ v3 (ฟรี) จาก themoviedb.org → Settings → API
- การ์ดจอ VRAM 4 GB ขึ้นไปจะเร็ว ถ้าไม่มีก็รันได้แต่ช้ากว่า

## วิธีติดตั้งและใช้งาน

```powershell
# 1) ติดตั้งไลบรารี (ควรทำใน venv)
pip install -r requirements.txt

# 2) ติดตั้งโมเดลภาษา
ollama pull qwen2.5:3b

# 3) เตรียมข้อมูล (ต้องต่อเน็ต) ใส่ API key ตอนที่สคริปต์ถาม
python tmdb_movies.py
python enrich_movies.py
python build_index.py

# 4) เปิดหน้าเว็บ แล้วเข้า http://127.0.0.1:7860
python app.py
```

ทุกครั้งที่ `movies.json` เปลี่ยน (เช่นรัน `tmdb_movies.py` ใหม่) ต้องรัน `enrich_movies.py` และ `build_index.py` ตามเสมอ ไม่งั้นรายการหนังกับดัชนีค้นหาจะไม่ตรงกัน

ดูจำนวนหนังที่มี:
```powershell
python -c "import json; print(len(json.load(open('movies.json', encoding='utf-8'))))"
```

## ปรับแต่ง

| ค่า | ไฟล์ | ความหมาย |
|---|---|---|
| `PAGES` | `tmdb_movies.py` | จำนวนหน้าหนังทั่วไป หน้าละ 20 เรื่อง (สูงสุด 500) |
| `THAI_PAGES` | `tmdb_movies.py` | จำนวนหน้าหนังไทยเพิ่ม |
| `LLM_NAME` | `rag.py` | โมเดล LLM ที่ใช้ |
| `LLM_CANDIDATES` | `rag.py` | จำนวนหนังที่ให้ LLM อ่าน (น้อยลง = เร็วขึ้น) |
| `OVERVIEW_CHARS` | `rag.py` | ความยาวเรื่องย่อที่ส่งให้ LLM |

**ใช้ Pathumma แทน Qwen:** นำเข้าไฟล์ GGUF ด้วย `ollama create pathumma -f Modelfile` แล้วแก้ `LLM_NAME = "pathumma"` ใน `rag.py` (Pathumma เน้นภาษาไทยแต่ช้ากว่าบนการ์ด 4 GB)

## แก้ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| `can't open file ... No such file` | ไฟล์ไปอยู่ในโฟลเดอร์ `venv` หรือคนละโฟลเดอร์ ตรวจด้วย `dir` ว่าไฟล์อยู่ข้าง ๆ โฟลเดอร์ `venv` |
| `ollama` ไม่รู้จัก | ติดตั้ง Ollama แล้วปิด-เปิด VS Code ใหม่ |
| error SSL ตอนโหลดข้อมูล/โมเดล | `pip install pip-system-certs` หรือโหลดไฟล์ด้วยเบราว์เซอร์ |
| เปิดตอนไม่มีเน็ตแล้วค้างที่ retry | ตรวจว่าบนสุดของ `app.py` ตั้ง `HF_HUB_OFFLINE=1` ก่อน import อื่น ๆ |
| โปสเตอร์ไม่ขึ้น | ตรวจว่ามีโฟลเดอร์ `posters` และรัน `tmdb_movies.py` สำเร็จ |
| หนังที่แนะนำไม่ตรง / ภาพผิดเรื่อง | รัน `build_index.py` ใหม่ให้ตรงกับ `movies.json` |
| ตอบช้า | ปิดโปรแกรมอื่นที่ใช้ RAM/การ์ดจอ และเช็กว่าโมเดลใส่ VRAM ได้ทั้งตัว |

## ข้อจำกัด

- ข้อมูลไม่มีบทพูดในหนัง ค้นด้วยประโยคที่ตัวละครพูดได้เฉพาะเมื่อสื่อถึงเนื้อเรื่อง
- LLM ขนาดเล็กอาจเลือกหนังหรือสรุปเหตุผลคลาดเคลื่อนได้ จึงแสดงรายการที่ค้นเจอไว้ให้ตรวจสอบ
- ค้นได้เฉพาะหนังที่อยู่ใน `movies.json`
- หน้าเว็บตั้งให้แสดง HTML ในแชท (`sanitize_html=False`) เหมาะกับการใช้ในเครื่องตัวเอง ไม่ควรเปิดให้คนทั่วไปเข้าผ่านอินเทอร์เน็ต
- อย่าเผยแพร่ API key หรือใส่ไว้ในโค้ดที่ส่งต่อให้คนอื่น
